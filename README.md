# Marketing Campaign Analysis Dashboard

## Project Overview
Analyzed 2,241 customer records to understand marketing campaign performance and customer behavior.

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed customer income by education level
- Segmented customers by marital status
- Analyzed wine spending by number of kids
- Built KPI cards, charts, and slicer

## Key Insights
- PhD and Master's degree holders earn highest (~56K)
- Married customers are largest group (38.57%)
- Customers with no kids spend most on wine (681K)
